Thank You for Installing Wordcode!

The programming language written entirely with English words.

🎉 Getting Started

Wordcode allows you to express code using clear, readable English phrasing. Wordcode source files use the .wc extension.

Quick Commands

Start Interactive REPL:

python3 -m wordcode

Run a Wordcode Script (.wc):

python3 -m wordcode examples/hello.wc

📜 Syntax Cheat Sheet

  • Variables: set count to ten
  • Display: display "Hello", count
  • Arithmetic: five plus ten, twenty minus seven, three times four, ten divided by two
  • Comparisons: is equal to, is greater than, is less than or equal to
  • Conditionals: if ... then ... else ... end
  • Loops: while ... end, repeat three times ... end
