🚀 Quick Start Guide

Get up and running in your terminal with Wordcode in seconds.

1

Launch REPL

Start the interactive Wordcode shell to execute commands live.

python3 -m wordcode
2

Run a Script

Execute any Wordcode file ending with the .wc extension.

python3 -m wordcode examples/hello.wc
3

Check Version

Verify your installation and current language version.

python3 -m wordcode --version

✨ Why Wordcode?

Designed for modern readability and effortless learning.

💬

Natural English Keywords

Express math operations and comparisons using natural words like plus, minus, divided by, and is equal to.

🔢

Word Numbers

Native support for English number words such as one, five, twenty, hundred alongside standard digits.

⚡

Clean Block Syntax

Self-explanatory control structures with if ... then ... else ... end, while ... end, and repeat ... times ... end.
